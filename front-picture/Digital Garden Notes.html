lightbulb 今日所学 (TIL)

Date: 2024-05-20 | Tag: Docker

学习了如何使用 Docker 多阶段构建 (Multi-stage builds) 来大幅度缩减 Go 应用的镜像体积。通过在一个阶段编译代码，然后将编译好的二进制文件复制到一个仅包含必要运行环境的轻量级基础镜像（如 Alpine 或 Scratch）中。 

# Build stage
FROM golang:1.20 AS builder
WORKDIR /app
COPY . .
RUN CGO_ENABLED=0 GOOS=linux go build -a -installsuffix cgo -o main .

# Final stage
FROM alpine:latest
RUN apk --no-cache add ca-certificates
WORKDIR /root/
COPY --from=builder /app/main .
CMD ["./main"]
